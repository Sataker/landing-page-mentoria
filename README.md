# AI automation mentoring: landing page

Landing page for Enzo Vaccaro's AI automation mentoring, in Portuguese.

Live at https://sataker.github.io/landing-page-mentoria/

- `index.html`: main page
- `minha-historia.html`: personal story and timeline

No build step: GitHub Pages serves these files directly from `main`. To preview locally, run `python3 -m http.server` and open http://localhost:8000.
